# texture-generator

Provides the modules to procedurally generate texture images. <br>
This repositroy is the submodule for
*  [TextureGenerator](https://github.com/taKana671/TextureGenerator)
*  [sky-archipelago](https://github.com/taKana671/sky-archipelago)

## What kinds of texture images can be created?

Also needs to use this repository [NoiseTexture](https://github.com/taKana671/NoiseTexture). <br>
Please see  [TextureGenerator](https://github.com/taKana671/TextureGenerator) for details.

### Sphere map

#### _An image for Sphere sky_

Applying this image as a texture to a sphere creates a spherical sky.

![Image](https://github.com/user-attachments/assets/6de22ecc-8759-4fee-b9dc-5759e5c29729)


#### _6 images for Sky box_

Create a sphere and use a 3D cube map to seamlessly wrap six images around its surface, creating a full-surround background.

![Image](https://github.com/user-attachments/assets/5dd59dc1-7c0b-45f4-a804-fccaa6cabe6d)
